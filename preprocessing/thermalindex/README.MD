 📌 This is a Python-based tool designed to estimate potential evaporation (PET) using Thornthwaite method .
 
 📦 The method requires three input variables: 
 ▪️ average temperature (Tavg)
 ▪️ minimum temperature (Tmin)
 ▪️ maximum temperature (Tmax). 
	To run the script, ensure that Python is configured on your system.
 
 📝 Before execution, update the file paths to match the location of your local data directory.
 
 📖 Please see the script comments for additional instructions.
 
 📖 A detailed description (daily_Thornthwaite_description.docx) of the estimation of daily potential evapotranspiration with the modified Thornthwaite method.
