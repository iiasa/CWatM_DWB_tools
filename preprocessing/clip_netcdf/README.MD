 📌 This is a script which clip input maps (and meteo maps) from the whole danube settings to a defined mask map.
 
 📦 To run the script, ensure that Python is configured on your system.
 
 📝 Input maps are all netcdf (.nc) files
	Mask map can be defined as .map or .tif map or specified by columns/rows, resolution, lat max, lon min.
	
📖  Please see the script comments for additional instructions.
