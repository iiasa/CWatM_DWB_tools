📌 This is a R-based Jupyter Notebook tool, developed to analyse different meteorological data sets. 

📦 To run the script, ensure that R, Python and Jupyter Notebook are installed on your system.

📝 Before execution, update the file paths to match the location of your local data directory.

📖 Additionally, this document presents the analysis conducted for the Danube Basin as part of the DWB project --> Danube_meteo.docx .
