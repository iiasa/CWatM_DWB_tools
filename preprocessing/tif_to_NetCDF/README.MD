📌 This is a script which converts GeoTIFF (.tif) files to NetCDF using a template NetCDF for metadata.

📦 To run the script, ensure that Python is configured on your system. Required packages: numpy, rasterio, netCFD4

📝 Input maps are all GeoTIFF (.tif) files.
Usage: python tif_to_netcdf.py --template template.nc --tif source.tif --output output.nc

📖 Please see the script comments for additional instructions.
